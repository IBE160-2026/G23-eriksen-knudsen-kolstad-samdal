# PRD-coaching-start

## 2026-11-04 kl. 20:20 — Idun-Samdal

### Oppgave
Starte coaching path for PRD til COSI - MRP på norsk og gjøre brukerens ønske om både MPS-planlegging og lagerbasert produksjonskapasitet tydelig i utkastet.

### Plan
- Oppdatere PRD-utkastet med begge inputgrunnlagene og valg av én eller begge beregninger.
- Loggføre brukerbeslutningen og videre avklaring.

### Resultat
- Oppdatert `.docs/planning-artifacts/prds/prd-COSI - MRP-2026-11-04/prd.md` lokalt: Excel-inndata skal støtte både MPS og lagerbeholdning; kunden kan kjøre MPS-materialplan, lagerbasert kapasitet eller begge i samme kjøring.
- Endringen er ikke committet eller pushet.

### Åpne punkter
- Avklar om lagerkapasitetsberegningen skal inkludere planlagte mottak og om sikkerhetslager skal reserveres.
