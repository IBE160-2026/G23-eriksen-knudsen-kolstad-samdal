# Avstemming: UX-spines mot PRD

Alvorlighet: **kritisk** = bryter et minstekrav eller hindrer kjerneflyten; **høy** = vil sannsynligvis gi feil mot et testbart krav eller ugyldig brukertest; **middels** = hull eller uklarhet som må lukkes før stories; **lav** = presisering eller ordbruk.

**Sammendrag:** 0 kritiske, 2 høye, 15 middels, 14 lave (31 unike funn). Ingen motstrid funnet for peking (hover), farge alene, kapasitetspanelet på samme side (FR-34) eller «ingen endringer» som begrep.

## 1. Dekning av krav med UI-konsekvens

Vurdert: FR-1–FR-34, NFR-1–NFR-11, SM-3, SM-C2, SM-C3, §4.4, §8.1, §9 nr. 4 og UJ-1–UJ-5 (56 punkter).

**Fullt dekket: 24.** FR-3, FR-4, FR-5, FR-6, FR-8, FR-15, FR-19, FR-21, FR-27, FR-28, FR-31, FR-32, NFR-4, NFR-5, NFR-6, NFR-7, NFR-8, SM-3, SM-C3, UJ-1, UJ-2, UJ-3, UJ-4, UJ-5. **Uten UI-konsekvens: 6** (FR-24, FR-25, NFR-1, NFR-2, NFR-3, NFR-11). **Ikke fullt dekket: 26** (tabellen under).

## 2. Motstrid mellom spines og PRD

| Tema | Resultat | Funn |
|---|---|---|
| Peking (hover) | Ingen motstrid | FR-18 er fulgt: peking åpner aldri noe, og DESIGN definerer ingen hover-tilstander som bærer informasjon. |
| Farge alene | Ingen motstrid | Eksepsjoner, kritiske deler, forfalt, endringer og begrensende deler har tekst eller ikon (EXP › Accessibility Floor, DESIGN › Colors). Merk T8: kritisk del på delnivå mangler merking helt, ikke bare tekst. |
| Rekkefølge (§4.4) | Ingen motstrid, men uforklart | Se T21. |
| Ordlyd i eksepsjoner | **Motstrid** | «Do»-eksempelet for Bestilling forsinket mangler opplysninger FR-10 krever. Se T5 (høy). |
| Kapasitetspanel på samme side (FR-34) | Ingen motstrid | «Begge» gir kapasitetspanelet sist på samme side, med egen lenke. Men se T17 om skillet: DESIGN gjør panelet visuelt likt Resultattabell, som går mot formålet i FR-34. |
| Eksportinnhold (FR-22, FR-23) | Ingen motstrid, underspesifisert | «Bare bestillingsplanen» stemmer med FR-30. Innhold, filnavn og filtre mangler. Se T12, T13. |
| «Ingen endringer» (FR-20) | Ingen motstrid, liten avvik | Teksten inneholder «ingen endringer», men nevner ikke deler. Etikettene avviker fra fasit 03. Se T11. |
| Begrensende del (FR-33) | Avvik i ordlyd | «(lager)» brukt også på raden med planlagte mottak, og bare én del vises. Se T16. |
| Intern inkonsistens | Avvik | Plasseringen av statusmeldingen (T19), og «Filen» i UJ-4-overskriften mot regelen om «fila» (se §4, O4). |
